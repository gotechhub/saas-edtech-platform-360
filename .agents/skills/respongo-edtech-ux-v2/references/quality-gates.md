# Quality gates

- TypeScript strict, unit tests, contract tests, and production build pass.
- Playwright covers five roles, two themes, route deep links, mobile navigation, and critical workflows.
- Automated accessibility checks have no serious or critical findings; keyboard, focus, zoom, high contrast, and screen reader behavior are reviewed manually.
- LCP p75 target is 2.5s, INP p75 200ms, CLS 0.1. Heavy charts and editors load on demand.
- Images have width/height, responsive formats, focal points, and meaningful alt text or an empty alt for decoration.
- Authorization is tested independently from hidden navigation.
- Completion requires code, responsive evidence, accessibility evidence, tests, and acceptance evidence. A screenshot alone is not completion.
